
# PINN Magnetic Field Reconstruction

Data and code associated with the manuscript:

**"Reconstruction of Magnetic Fields with a Physics-Informed Neural Network"**

## Authors

P. Adhikari et al.

Department of Physics and Astronomy  
University of Kentucky

## Contents

- `data/` — datasets used in the analysis
- `code/` — PINN and magnetic-field reconstruction code

## Data

The repository contains data used for the B0 magnetic-field reconstruction
and Spin-Transport Coil (STC) reconstruction.

## Code

The code implements physics-informed neural-network reconstruction of
magnetic fields using Maxwell-equation constraints.
